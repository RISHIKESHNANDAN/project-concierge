# Returns Policy
SYNTHETIC DOCUMENT for the ShopEase exercise.

## Return window
You can return most items within 30 days of delivery. Items must be unused and in their original packaging.

## Return shipping costs
Returns for defective, damaged or wrong items use a free prepaid return label. For any other reason (for example, you changed your mind) a $4.99 return shipping fee is deducted from your refund.

## Items that cannot be returned
Gift cards, personalized items and perishable goods are non-returnable.

## How to start a return
Go to Account > Orders > select the order > Return item. Print the label and hand the parcel to the carrier within 7 days of creating the label.
